# مخازن التخزين المؤقت

تطبيق ويب عربي لإدارة المخازن والتحويلات بين المستودعات.

## التشغيل المحلي

```bash
npm start
```

ثم افتح:

```text
http://127.0.0.1:5174
```

## التشغيل أونلاين

التطبيق جاهز للنشر على استضافة Node.js، ويدعم التخزين السحابي عبر Supabase.

ملفات النشر المهمة:

- `package.json`: أمر التشغيل.
- `server.js`: السيرفر وواجهة API.
- `supabase-schema.sql`: جدول قاعدة البيانات.
- `.env.example`: أسماء متغيرات البيئة المطلوبة.
- `DEPLOY.md`: خطوات النشر.

## التخزين

بدون Supabase يستخدم التطبيق `db.json` للتجربة.

عند إضافة:

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

ينتقل التخزين تلقائيًا إلى Supabase.

## حسابات البداية

- الأدمن: `ADMIN` / `1991`
- المستودع الرئيسي: `MAIN` / `1111`
- مستودع الناصرية: `NASIRIYA` / `2222`
- مستودع الصفا: `SAFA` / `3333`
